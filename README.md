# GProject - Bootstrap 5 Carousel, Flexbox, Font Awesome & Forms

Dự án thực hành sử dụng **Bootstrap 5.3.3** kết hợp **Font Awesome 6.5.2** để xây dựng trang web tương tác hiện đại.

## 📌 Các thành phần chính theo từng bước:
1. **Cài đặt thư viện**:
   - Bootstrap 5.3.3 CSS & JS Bundle CDN.
   - Font Awesome 6.5.2 CDN.
2. **Navbar với Font Awesome**:
   - Biểu tượng `<i class="fas fa-home"></i>` tại Brand `MyWebsite`.
   - Danh sách menu: Home, About, Services, Contact.
3. **Hero Section với Carousel (`#heroCarousel`)**:
   - Slideshow hình ảnh tự động chạy (`data-bs-ride="carousel"`).
   - Nút chuyển ảnh trước / sau (`carousel-control-prev`, `carousel-control-next`).
4. **Section Flexbox**:
   - Sử dụng `.d-flex.justify-content-center.align-items-center.bg-light.py-5` căn giữa tiêu đề.
5. **Contact Form**:
   - Form liên hệ với các trường: Tên của bạn (`form-control`), Email (`form-control`) và nút Gửi (`btn btn-primary`).

## 📁 Danh sách tệp tin:
- `index.html`: Giao diện hoàn thiện cao cấp.
- `carousel-flexbox-exact.html`: Mã nguồn chuẩn nguyên mẫu theo đề bài.
- `image1.jpg`, `image2.jpg`: Hình ảnh trình chiếu Carousel.
- `bootstrap-carousel-sample.png`: Ảnh chụp kết quả chạy trên trình duyệt.

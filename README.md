# GProject - Bootstrap Landing Page (MyBrand)

Dự án thực hành xây dựng **Landing Page chuyên nghiệp** sử dụng thư viện **Bootstrap 5.3.0**.

## 📌 Các thành phần chính của Landing Page:
1. **Navbar (`.navbar-expand-lg.navbar-dark.bg-dark`)**:
   - Thương hiệu: **MyBrand**
   - Menu điều hướng: **Home**, **About**, **Services**, **Contact**
   - Nút Hamburger Toggler mở menu trên thiết bị di động.
2. **Hero Section (`<header class="bg-primary text-white text-center py-5">`)**:
   - Tiêu đề: *Chào mừng đến với MyBrand*
   - Khẩu hiệu: *Giải pháp số 1 cho doanh nghiệp của bạn*
   - Nút kêu gọi hành động (Call To Action): *Khám phá ngay*
3. **Grid System & Cards - Services (`<section id="services">`)**:
   - Sử dụng hệ thống lưới Bootstrap Grid (`row`, `col-md-4`) chia làm 3 cột dịch vụ:
     - 🌐 **Thiết kế Web**: Dịch vụ thiết kế web chuyên nghiệp.
     - 🚀 **SEO & Marketing**: Nâng cao thương hiệu của bạn.
     - 💬 **Hỗ trợ 24/7**: Chúng tôi luôn sẵn sàng hỗ trợ bạn.
4. **Footer (`<footer class="bg-dark text-white text-center py-3">`)**:
   - Bản quyền: `&copy; 2024 MyBrand. All rights reserved.`

## 📁 Danh sách tệp tin trong dự án:
- `index.html`: Landing page hoàn chỉnh với thiết kế thẩm mỹ cao, chuẩn Bootstrap 5.
- `landing-page-exact.html`: Mã nguồn chuẩn 100% từng dòng theo đề bài hướng dẫn.
- `style.css`: Các tùy biến CSS bổ trợ giao diện hiện đại.
- `bootstrap-landing-sample.png`: Ảnh chụp giao diện theo đúng đề bài mẫu.
- `bootstrap-landing-desktop.png`: Ảnh chụp giao diện Desktop chuẩn.
- `bootstrap-landing-mobile.png`: Ảnh chụp giao diện Mobile responsive.

## 🚀 Tính năng Responsive:
- **Desktop (màn hình lớn):** Navbar dàn ngang, 3 thẻ Card dịch vụ xếp thành 3 cột song song.
- **Mobile (màn hình nhỏ):** Navbar thu gọn vào nút 3 gạch, các Card dịch vụ tự động xếp chồng theo chiều dọc một cột duy nhất giúp đọc dễ dàng.

Thực hành các loại danh sách trong HTML (HTML Lists)

1. Danh sách mua sắm (Unordered List - <ul>)

  • Sữa tươi tiệt trùng
  • Trứng gà sạch
  • Bánh mì ngũ cốc nguyên cám
  • Rau xà lách và cà chua
  • Táo đỏ và chuối chín
  • Thịt bò phi lê

2. Danh sách công việc cần làm trong ngày (Ordered List - <ol>)

  1. Thức dậy lúc 6:00 sáng và tập thể dục 30 phút
  2. Ăn sáng bổ dưỡng và uống đủ nước
  3. Tham gia lớp học trực tuyến môn Lập trình Web
  4. Thực hành tạo các loại danh sách trong HTML (ul, ol, nested list)
  5. Kiểm tra lại mã nguồn và mở trên trình duyệt web
  6. Chụp ảnh màn hình giao diện bài tập để nộp bài
  7. Đọc trước tài liệu về bảng biểu (Table) trong HTML cho buổi sau

3. Danh sách lồng nhau (Nested List)

  • Lộ trình học Lập trình Web Front-end
    1. HTML (HyperText Markup Language)
      • Cấu trúc cơ bản và thẻ tài liệu (<html>, <head>, <body>)
      • Định dạng văn bản (<h1>-<h6>, <p>, <b>, <i>)
      • Danh sách (<ul>, <ol>, <li>)
      • Liên kết (<a>) và hình ảnh (<img>)
    2. CSS (Cascading Style Sheets)
      • CSS Selectors và độ ưu tiên
      • Màu sắc, font chữ và căn chỉnh văn bản
      • Mô hình hộp (Box Model: Margin, Border, Padding)
      • Flexbox và CSS Grid Layout
    3. JavaScript cơ bản
      • Biến, kiểu dữ liệu và toán tử
      • Hàm và vòng lặp
      • DOM Manipulation và xử lý sự kiện (Event Handling)
  • Công cụ hỗ trợ học tập
    • Trình soạn thảo mã: Visual Studio Code
    • Hệ thống quản lý phiên bản: Git & GitHub
    • Trình duyệt kiểm thử: Google Chrome / Microsoft Edge

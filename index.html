THỰC HÀNH THUỘC TÍNH CSS FLEX-BASIS

Ví dụ 1: flex-basis với đơn vị px (Kích thước cơ sở theo chiều ngang)

Item 1 (200px) | Item 2 (100px) | Item 3 (150px)

Item 1 (200px)
Item 2 (100px)
Item 3 (150px)

Ví dụ 2: flex-basis thay đổi theo flex-direction: column (Theo chiều dọc)

flex-direction: column; height: 380px; | .item { flex-basis: 90px; }

Item 1 (100px dọc)
Item 2 (100px dọc)
Item 3 (100px dọc)

Ví dụ 3: flex-basis với tỷ lệ phần trăm %

.item { flex-basis: 50%; box-sizing: border-box; }

Item 1 (50%)
Item 2 (50%)

Ví dụ 4: Kết hợp flex-basis (100px) với flex-grow (Tỷ lệ 1 : 2 : 1)

Mỗi item có flex-basis: 100px | Item 1 (grow: 1), Item 2 (grow: 2), Item 3 (grow: 1)

Item 1 (basis 100px, grow 1)
Item 2 (basis 100px, grow 2)
Item 3 (basis 100px, grow 1)
